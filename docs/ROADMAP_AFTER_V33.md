# OpenViz Studio — Proposed roadmap after V3.3

These are priorities, not release promises. All releases retain the browser-based, local-first, free, no-AI identity.

| Milestone | Goal | Acceptance emphasis |
|---|---|---|
| **V3.4** | Interactive dashboards: cross-chart highlighting, linked selections, filter coordination | Correct field mappings across datasets, no silent assumptions, responsive dashboards |
| **V3.5** | Publishing and embedding polish: responsive previews, embed code, static/interactive export presets, attribution/branding controls | Hosting without accounts, portable files, privacy, embeddability, no paywalled controls |
| **V3.6** | Data storytelling: soundtrack/audio tracks where locally supplied and licensed, more advanced keyframes and export presets | Sync and export fidelity, correct reduced-motion support, robust video formats |
| **V3.7** | Advanced geographic and specialised views, where evidence supports demand | Honest geographic precision, map data provenance, chart-specific controls |
| **V4.0** | Public-beta/stable milestone, contingent on field testing | Saving/recovery, accessibility audit, compatibility, performance and security tests |

**Continuing work throughout:** downloadable backups; native editable PPTX where practical; typography/academic figure fidelity; large-file and Web Worker cross-browser testing; performance transparency; user documentation.
