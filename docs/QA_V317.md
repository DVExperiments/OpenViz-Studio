## Semantics and bounds

Seven snapshot types are supported: bar/hbar/dot/scatter/bubble/geo-choropleth/geo-symbol. Frames are independent observations, not interpolated positions. Numeric/date periods sort; other labels follow source order. Constant XY domains expand for visible placement; changing periods never recomputes the domain. Duplicate point IDs are rejected before rendering. Invalid numeric records and missing IDs are excluded; no silent sampling is used in time point views.

Limits: 60 periods, 30,000 rows, 400 valid point observations per period, 6 MiB escaped frame payload including the first displayed snapshot. Styles/code/runtime memory are additional. Repeated map paths are stored once and restored locally. Static output remains a saved-period snapshot. Heatmap time controls, ordinary snapshot timeline GIF/video, trails/interpolation and animated story states remain gaps.
