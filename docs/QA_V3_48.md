# V3.48 QA — overlapping area snapshots

## Passed

49 automated suites: 48 regular suites and the studio DOM suite. The new area suite checks seventeen snapshot types; five per-cell aggregations; distinct period/X/series/value roles; fixed zero-anchored domains; numeric/date/categorical spacing; coordinate aliases; missing-measure-only known X positions; gaps in both fills and outlines; isolated and zero observations; empty periods; stable colours/legend; and all fills behind every outline/marker. Overlapping series with values 8 and 8 share the same polygon and maximum 8, not a stacked height 16.

Negative numeric source contributors reject playback even if a group's net aggregate is positive; Count ignores measure values. Caps, finite large values and overflow are checked. Dashboard filters retain saved period/domains; out-of-range averages break fills/lines and retain disclosed original values. XML validity is checked across three widths, two themes and four periods. Portable import, rename/raw preservation, story capture and source immutability pass. Executed export scripts check literal script-like labels, current-period keyboard details and saved-period dashboard filtering.

The studio test uses the actual template/example and period selectors, verifies fill runs and empty periods, captures a period with Undo, publishes the player and restores prior chart/dataset state. All earlier suites pass.

## Pending and boundaries

Normal Chromium launch exited before opening a page. Native browser layout/focus/touch, screen readers, Windows, real-origin storage, native export viewers/codecs and detailed performance acceptance remain pending. Automated DOM/XML tests do not substitute for those checks. Competitor parity is unclaimed.

Areas overlap from zero and are not stacked. Missingness is relative to known source X positions, not a fabricated regular grid. Numeric measures must be nonnegative; Count can turn labelled missing measures into observations. Per-point colour overrides affect markers, not the series fill. Manual Y bounds are overridden by timeline bounds. Filtered out-of-range aggregates use boundary details and break geometry; overflow rejects partial output. Limits: 60 X positions, 10 series, 60 snapshots, 30,000 rows and 6 MiB player markup. No carry-forward or between-snapshot interpolation. Standalone chart HTML includes all periods; static/dashboard/story outputs use the saved period. Published payloads can expose source/aggregate values.
