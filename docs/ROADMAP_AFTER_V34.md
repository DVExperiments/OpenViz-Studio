# Suggested OpenViz Studio roadmap after V3.4

The following are **proposed** scopes, not committed release dates.

| Milestone | Focus | Example deliverables |
|---|---|---|
| V3.4.1 (only if needed) | Linked dashboard polish | Browser QA fixes; accessible selection; support larger category exports |
| V3.5 | Professional website publishing & embeds | Responsive embed previews, iframe code generation, interaction settings, portable publish presets |
| V3.6 | Story Studio professional workflows | Audio-track experiments, improved timeline editing, motion export quality and duration precision |
| V3.7 | Advanced dashboard data linking | Explicit joins/mapping, multi-filter rules, transparent treatment of unmatched categories |
| V3.8 | Accessibility, export and reliability gates | Cross-browser keyboard access, screen-reader chart descriptions, export regression coverage |
| V4.0 (future) | Public beta/stable milestone | User documentation, security/performance audit, regression suite, release distribution, known-limitations disclosure |

Remain faithful to OpenViz's product goal: visualisation software first, not a replacement for Excel. Keep local-first/browser-based, optional non-AI advice and unrestricted design customisation.
