## Pending / limitations

A normal headless Chromium launch using the installed executable failed before a page opened (browser closed). Native layout, file picker, Windows persistence, browser performance with real detailed boundaries, screen-reader behaviour and video recording remain unverified. DOM/geometry mocks and SVG renders do not certify these.

Structural coordinate/ring checks do not validate full topology, intersections, hole containment or overlap. Projection is fitted local equirectangular, not equal-area. Custom mode is choropleth only, with tooltip/accessible labels but no on-map text labels. Geographic IDs that collide under legacy dashboard filter normalisation cannot originate selections. Static interactive custom maps omit the generic category filter; time HTML retains its time player. No external boundary downloads or hosting were added.
