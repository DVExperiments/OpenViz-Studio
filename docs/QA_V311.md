# V3.11 validation

## Automated checks passed

`tests/test-quality-v311.mjs` covers all 41 types: valid SVG XML and finite geometry with long headings at 360/768/1440 × light/dark chart palettes, wrapped-title width estimates, custom description metadata, three HTML layout variants, actual standalone keyboard/focus/arrow/Escape behaviour and optional source tables. Table fixtures test search, numeric sorting, page bounds, missing/zero distinction, excluded unbound columns, 5,000-row cap and escaped hostile labels. Static chart publications remain script-free. Dashboard runtime is checked too.

`tests/test-studio-v37.mjs` now checks actual description/source/table settings and undo/source safety, actual 360/700 device SVG widths and publication review guidance, in addition to all 41 existing field/source/undo workflows. `tests/test-expanded-runtime-v39.mjs` executes generic and research standalone scripts in jsdom. The expanded model, research arithmetic, field contract, map note, publishing, dashboard linking, rename/story, storage and synthetic performance suites also passed.

Set OPENVIZ_DOM_MODULE to an installed jsdom module when needed. Run Node tests directly. `tests/render-quality-v311.mjs` generates repeatable SVG fixtures for static visual inspection; CairoSVG can rasterise them.

## Visual inspection

CairoSVG output was inspected for nine representative templates at 360 and 960 widths, with intentionally long headings and source credits. This caught and corrected a stacked-column legend collision and redundant generic legends. These are static renderer checks, not browser screenshots or a full visual certification of all 41 charts.

## Pending and limits

A normal Playwright Chromium launch was attempted and failed because the browser process closed in this environment. No workaround to the environment restrictions was attempted. Full browser UI, CSS container-query behaviour, real screen readers, keyboard use across nested dashboard controls, cross-browser layouts, real-origin IndexedDB, destination embeds and native Windows exports need hands-on verification.

Text widths are estimates; custom font layout and manually set margins can still overlap. Headings are limited to two lines; full text remains in metadata/title tooltips. Existing category/cohort/render limits still apply. HTML responsive exports contain three complete layouts, increasing file size and generation time. Browsers without container-query support fall back to the wide layout. Free-canvas dashboards retain their fixed positions and may need scrolling. Story animations keep their fixed canvas geometry; they do not receive the three-layout HTML chart wrapper.

Optional source tables expose a bounded snapshot of original values, not recomputed chart mark values, and do not change when chart filters or Assumption controls change. Their explanatory caption stays visible. Static tables have no search/sort/paging. Source snapshots are off by default and contain at most 12 bound columns. Interactive stories do not include these tables in this release. Public export descriptions/tooltips can reveal values even when the table is off.

No accessibility compliance, competitor quality superiority or complete feature parity is claimed.
