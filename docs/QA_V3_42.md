## Pending acceptance / limits

Normal /usr/bin/chromium launch exited before opening a page. Native layout, browser keyboard/focus/touch, screen readers, Windows and detailed performance acceptance remain pending. No competitor parity claim.

The matrix template is distinct from geographic density heatmaps. Timeline columns/rows are the union of valid cell contributors in ordered periods, first appearance retained. Missing dimension labels are excluded (not renamed Unknown in time mode). Numeric missing/invalid values are excluded except Count, which counts records with both labels regardless of measure. No empty years are fabricated; an observed invalid-only period remains empty. Grouping uses exact string categorical identity, not fuzzy matching. Label clipping may shorten display; mark details keep complete categorical labels.

Colour is a sequential opacity scale against chart background with a lower bound at most zero and upper bound at least one; signed values are supported. The zero-anchored 0–1 reference avoids degenerate all-zero ranges. It is fixed within a timeline, not synchronized between independent charts or filtered story sources. Per-cell overrides bypass scale. Manual yMin/yMax do not author colour limits. Theme/background affects perceived lightness. Grey missing cells remain distinct from numeric zero.

32 columns/16 rows across the full timeline, 60 periods/30,000 source rows/6 MiB player payload. Size/overflow violations reject playback rather than publishing partial cells. Static heatmaps retain previous caps/semantics. Interactive chart HTML includes all snapshot aggregates; optional source-data tables and portable projects can contain source records. Dashboards/story/static use saved periods; dashboard filters reference the complete unfiltered chart timeline. Scene filters define a new source timeline and may change colour/domain, so avoid comparing differently filtered scenes as if a shared authored scale were present.
