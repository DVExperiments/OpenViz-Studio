## Scope and limits

Saved state contains bounded presentation options and up to 400 colour overrides, named time/race period and an optional role-based filter of at most 100 values. Data, calculations, source type/mappings, image assets and race captions remain linked. It is not a frozen data snapshot. Changing a scene source clears local state/focus. Unsupported saved-state versions show an error rather than falling back silently to the live chart.

Matching requires the same linked chart, identical plot bounds/domains/axes and 1–400 unique leaf rectangle/circle marks, with no custom transforms and a compatible ending pose. Other chart types, map paths and moving/rescaled axes crossfade. Incoming matching scenes use their complete static source view during/after entry; layer reveal keyframes are skipped. Interpolated geometry is explicitly not an observation.

HTML uses bounded sampled frames (maximum 180) and a 24 MiB escaped frame payload budget including the static fallback. Frame code/styles/runtime overhead are additional. Important boundaries are retained; an insufficient custom frame budget produces an error. GIF variable delays are floored to 20 ms and redistributed to preserve total duration, then quantised to centiseconds. Optional smooth-loop blending is unchanged and was not used in the decoded fixture.
