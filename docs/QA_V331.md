# OpenViz Studio V3.3.1 — Focused QA report

## Scope
Built from **V3.3** to address direct user feedback about column renaming and the Story Studio video-editor timeline. This does not replace the planned V3.4 linked-dashboard milestone.

## Verified using the isolated Chromium app harness
- Renaming a field from `Year` to `Fiscal Year` updates editable dataset rows and `columns` metadata, preserves the original import (`rawRows`), writes an audit entry, and updates the linked chart's X mapping.
- Duplicate and invalid new field names are rejected in the dataset-edit contract tests.
- Clicking one of the green scene blocks selects that specific scene and moves the preview playhead to its animation.
- Dragging a green block's right edge increases its saved duration. Keyboard Left/Right (100 ms; Shift for 500 ms) also works.
- New scene default: **5,400 ms total**, **2,600 ms animation**, remaining **2,800 ms hold** before transition overlap.
- Existing scene fallback: a default animation duration shorter than its saved scene duration; **existing scene durations are not silently extended**.
- The same SVG frame is produced at two distinct timestamps within the completed-chart hold (no unintended animation during hold), while an earlier frame differs.
- Clicking a keyframe seeks the preview to its exact corresponding time, and editing its opacity saves the new keyframe property.
- Keyframe display indicates the playback portion of the clip versus the static hold. A point-focus warning appears when the point track has no active selection.
- The V2.11 natural motion suite passed across all **25 working chart types**, including a GIF generation check (see the copied regression output in the release notes).

## Testing still required / not certified
- Normal-origin IndexedDB saving and restoration of **V3.3.1** after a full browser reload.
- Opening V3.3.1 exported `.openviz` in a separate browser / device and checking renamed fields and new `animationMs` scene setting.
- Manual GIF/MP4/HTML preview fidelity in Chrome / Edge / Firefox / Safari.
- Two older V3.2/V3.1 combined automation scripts stalled in this run (no passing result claimed). No new export engine was changed; the shared Story SVG compositor is retained.
- Broad accessibility testing across screen readers and fully responsive small-screen editing.

## Technical changes
`src/dataset-edit.js`: `renameDatasetColumn`, dependency-aware remap.
`src/story.js`: new scenes' animationMs / duration defaults, normalized legacy fallback, finite hold in compositor.
`src/app.js`: data-header rename dialog, interactive scene ruler, clip-edge dragging/keyboard resize, preview-sync on keyframe selection, live keyframe inspector changes, explanatory point-track warning.
`src/styles.css`: rail, clip handles, hold region and accessible rename buttons.

## Manual owner checks
1. Export an `.openviz` backup before upgrading.
2. In Data, rename a country/region or year column using its pencil icon; reopen an existing linked chart to confirm the mapping and values remain correct.
3. Open a two-scene visual story. Select scenes by clicking the green ruler blocks; drag the right edge of the first block to make it longer.
4. Observe the first animation, the hold on the completed chart, then the transition to the second.
5. Select a diamond in Chart titles, change its opacity, verify preview changes; try Selected data point, and choose a Focus a data point before editing that track.
6. Export the visual story as HTML and GIF, and confirm that the timing matches its editor preview.
