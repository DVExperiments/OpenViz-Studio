## Pending acceptance and limits

Normal headless /usr/bin/chromium launch exited before opening a page. Native browser layout, focus/keyboard/touch, screen readers, Windows and detailed performance acceptance remain pending. No workaround was used to claim native acceptance.

Discrete playback only: no geographic/magnitude interpolation or carry-forward. Exact pair identity includes full labels and coordinates; explicit IDs allow movement but cannot repeat in the same period. Grouping ignores row IDs and uses directed-pair identity per period. Frames exclude invalid values/coordinates and selected missing IDs. Invalid-only periods render an empty basemap, provided another period has valid routes; a wholly invalid timeline is rejected.

60 periods, 30,000 source rows, 500 resulting connections per period and existing 6 MiB player payload budget. Source data is never rewritten. Fixed framing includes valid paths in the included timeline; authored crop can clip paths. Curves remain illustrative. Independent charts/scenes require matching authored maximum/line width/display scale for visual comparability. Scene filters define their own timeline reference. Dashboard filters use the unfiltered chart timeline but render only saved-period matching rows. Uniform widths ignore magnitude scale.

Interactive chart HTML embeds all snapshots; dashboard/story outputs remain saved-period views. Stable timeline context uses a deterministic fingerprint for reader continuity, not a security or cryptographic guarantee. Full competitor parity remains unclaimed.
