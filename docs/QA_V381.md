# V3.8.1 QA — compact editor and map notes

## Implemented

Desktop/tablet project panel opens by default. Narrow screens retain the existing on-demand overlay. Collapsible section state remains a browser preference; default-open applies to the panel, not to overriding the user's section choices.

The screenshot's floating tabs came from a 57 px toolbar combined with a more specific 29 px generic toolbar-button height. The studio toolbar now has a fixed 42 px height, and higher-specificity tab rules give Preview/Data full height, square corners and a bottom-aligned active border. Project/Settings headers and narrow inspector/resize overlays match that baseline.

geoShowBoundaryNote is a boolean setting, false by default. Only true renders the map source/boundary note. The control is in shared Map appearance, so it works for choropleth, symbol and density maps. Existing projects without the flag default to hidden. Map geometry, margins, legend and source values are unchanged; provenance information remains in Map appearance and bundled documentation.
