# V3.31 QA — custom map tooltips

All 32 automated suites passed: 31 model/runtime/contract groups plus the extended studio harness. The existing spatial-time suite caught the current period being inserted into the fixed domain object; implementation was corrected to use separate transient timeDisplayPeriod metadata. The original strict fixed-domain equality test then passed unchanged, along with the new tooltip and editor suites. No unresolved automated failures.

New test-map-tooltips-v331.mjs covers Automatic fallback, custom labels, decimal/compact/scientific/exact values, optional exact rows and visibility, contributing counts/aggregation, genuine zero, missing states/periods, invalid settings, escaped labels and ARIA, unchanged paths/fills/symbol positions/radii/source data, sum/mean/min/max/count, country alias aggregation, coordinate-bound versus representative locations, regional manual anchors, symbols' background-country context, responsive/theme SVGs, portable rejection/roundtrip, saved stories, chart/dashboard publication, executed keyboard focus/arrows/Escape, stale-frame tooltip dismissal and standalone Next with current-period values.

Extended studio harness covers example creation, modal controls, sample/interactive preview, Preview/Cancel/Apply/one-step Undo, hidden values retaining exact metadata, invalid limits/text/missing-data text, disabled controls, Automatic restoring prior titles while keeping preferences, symbol coordinates, stale-binding rejection and Publishing Studio/source safety. Storage is mocked; real-origin persistence remains uncertified.

Prior quality, data contracts, expansions/runtime, map class/diverging/domain/scales/legend/context/authoring/canvas/projection/note, regional map/symbol, race/assets/presentation/export, ordinary/spatial time, publishing, saved/scroll story, research, storage, dashboard/rename and performance checks pass.

16 map SVGs generated across four map examples, two widths and two themes, plus four text cards derived from actual SVG tooltip titles. Representative maps and cards rasterised with Sharp/libvips and inspected. docs/v331-map-tooltip-examples.png is generated map output plus rendered tooltip text, not a native hover screenshot. Four-chart/three-dataset/dashboard JSON validates; standalone HTML retains current-period tooltip text.

Normal native Chromium launch attempted and failed before opening a page. Native font/modal/hover layout, touch, Windows, screen readers and real-world detailed-map acceptance remain pending. Plain-text tooltips are bounded by existing runtime wrapping; long names/labels can still require native layout review. Additional unbound fields, rich HTML and custom tooltip styling are not implemented. Hidden display rows do not redact project/publication data. No identical-data competitor benchmark.
