## Semantics and limits

Line races use a stable peak-selected subset, fixed signed Y scale and numeric/date X spacing; playback time per observed step is equal. Only neighbouring present values interpolate. Missing pairs remain gaps unless explicitly zero-filled. Race limits: 120 periods, 100 source entities, 15 displayed lines. Static/dashboard/story views are snapshots. Range export recomputes the included model, scale and peak selection. Existing GIF/video resource limits still apply.

Ordinary time controls support column/horizontal-bar/dot only: 60 periods, 30,000 rows, 6 MiB playback markup. Each period uses the existing aggregation model, with fixed global value bounds overriding manual bounds. Missing categories disappear; no interpolation or carry-forward. These controls do not add timeline GIF/video export to ordinary charts. Static exports use the saved period. Bound source tables, when opted in, can contain all periods before chart filtering.
