# V3.64 handoff (usability fixes)

The baseline is V3.63. The findings and the remaining backlog are in `docs/USABILITY_REVIEW_V3_64.md`.

## Changes

### `editor/export-ui.js` `openExport()`: the "Save or share" dialog

- It is grouped as: Save a copy (PNG, PDF, PPTX, video), Put it on a website (`publish-open`, interactive HTML), Keep a backup (`export-project`), and More formats in a `<details>` (SVG, static HTML, PowerPoint report).
- The header button now always uses `data-action="export"` and reads "Save or share".
- Browser flows that clicked `#headerExport` to reach the Publishing Studio now also click `[data-action=publish-open]` in the dialog. The patched scripts are in `tools/verification/*.py` and `/home/claude/tools/*.py`.

### Region recognition

- **Files:** `src/boundaries/region-names.json` holds about 62 KB of `{ISO3: [names]}`. It is generated by `tools/build-boundaries.mjs`.
- **`regional-map.js`:**
  - `looseName(v)` folds diacritics, case, apostrophes and punctuation. It also drops generic words (district, city, region, province, state…) and turns `wh` into `w`.
  - It adds join mode `geoJoinMode:'loose'`, alongside `exact` and `trim-fold`. The custom-boundary dialog offers it as "Forgiving".
- **`map-library.js`:**
  - `loadRegionNames()` / `primeRegionNames()` and `matchRegionCountry(values)`. A match needs at least 2 names and at least 50% of distinct values matching one country.
  - `regionMapSettings(iso3)` returns the settings for the admin-1 set: `geoBoundaryKey/Label:'name'`, `geoJoinMode:'loose'`, and the extent from `countryStarter`.
- **`app.js`:**
  - `render()` now wraps `renderCore()` and then calls `regionSuggestion()` for geo-choropleth or geo-symbol charts without `geoCustom` whose warning strip reports no matches.
  - `use-region-map` → `useRegionMap(iso3)`. It ensures the set, applies the settings, and is undoable.

### Chart chooser suggestions

- **`catalogue.js`:** `suggestTypesForRows(rows, x, y)` gives an ordered list of types:
  - Time-like x → line, bar, area, table, kpi.
  - ≤6 positive categories → bar, hbar, donut, pie, table.
  - ≤40 categories → hbar, bar, lollipop, dot, table.
  - More than that → hbar, table, histogram, dot.
- **Group state:** `setSuggestedTypes` / `suggestedTypes` hold the suggested types. `CATALOGUE_GROUPS` starts with `suggested`, which is shown only when it is non-empty. `catalogueSearch` keeps that group in the suggested order.
- **`openChartChooser`:**
  - With a dataset, it computes the suggestions and opens with `group:'suggested'` and `source:'mydata'`. The Preview select now reflects this.
  - The introduction is now plain language.
- **Import:** importing from Home (`home-data`, including the sheet picker for new projects) opens the chooser after `addDataset`.

### Settings, Home, wording

- **Settings:** `simplifyStudioSettings(root, c)` hides Studio sections that don't match `SIMPLE_SECTIONS` (Time controls stays visible only when time is enabled). It adds **Show all settings (N more)**. The choice is stored in `localStorage['openviz-all-settings']`. The label-rules section is renamed "Which values get labels".
- **Home:** "Your projects" is rendered before the templates when any project exists. The project cards' `aria-label` was removed, so the accessible name matches the visible text (axe label-content-name-mismatch).
- **Titles:** default titles are now `"<y> by <x>"`. The auto-title sync handles both the old and the new pattern.
- **Data page:** the heading is "Check your data" or "Add your data", with buttons "Make a chart →" and "＋ Add another file".
- **Names and labels:**
  - "Shaded map (choropleth)" and "Bubble map (proportional symbols)", in `CHARTS` and `CATALOGUE`.
  - Plain labels in Data & axes (`PLAIN` map).
  - The line/area "categorical X" warning is skipped for month, weekday and quarter names, and reworded.
