## Pending / limits

Full browser/container-query/touch/animation behaviour, real screen readers and native Windows export inspection remain pending. Earlier Chromium launch attempts failed in this environment; no new successful browser run is claimed.

History shows one entity at a time. Its X positions follow equal race steps, not elapsed time; Y uses the global race maximum. It is omitted if plot height is below 280 pixels. With many bars on a short existing canvas, increase height or turn history off. Captions are at most 400 characters and static text wraps to two lines; the full text remains available in interactive player text and SVG title metadata. Captions for periods absent after a source switch are preserved but not displayed. A stale saved history entity falls back to the highest-peak entity with guidance. Interactive HTML exposes all known-period captions, even if currently hidden.

Player history selection is transient. The default entity is saved in Template options. Caption editing uses the selected static-export period, not an in-between animation value. Captions are not generated or fact-checked automatically; the built-in captions refer only to illustrative example values.

GIF/video race recording, images/flags, simultaneous multi-entity timelines and caption start/end intervals remain unimplemented. Static dashboard/story exports remain snapshots.
