# V3.34 QA — transient map navigation

## Automated coverage

35 complete suites, including the extended studio suite. New test-map-navigation-v334.mjs covers:

- Off by default; independently enabled from search. Unsupported heat maps excluded. Portable boolean validation.
- Bounded 1–8× zoom, bounded normalized pan and exact identity reset.
- Two clipped transform layers: geographic marks and names/callouts; fixed title, legend, locator and ocean frame. Country and custom-region maps, symbols/areas, 360/960 SVG XML/numeric geometry.
- Inverse screen-CTM drag coordinates, movement threshold, click suppression, Escape rollback, no wheel interception.
- Time/responsive continuity, projection/context reset, independent dashboard cards and self-contained script execution.
- Search/pin/current-period coexistence and independent flag, clean static output, editing block, cleanup and unchanged source settings/rows.
- Editor external controls, toggle/Undo, no reader Undo entries, time continuity, clean publication and zoomable example creation.

Existing complete contracts/runtime regressions cover prior features. DOM checks do not certify physical pointer capture, rendering, focus visibility or assistive technology.

## Examples

Five editable maps, four datasets and a dashboard in examples/v334-zoomable-maps.json; regional and point-time standalone HTML. Twenty navigation-enabled SVG fixtures generated across two widths and two themes. Render script is tests/render-map-navigation-v334.mjs. A four-map comparison was rasterised with Sharp/libvips and inspected: docs/v334-map-navigation-examples.png. It illustrates generated SVG transforms, not a native browser screenshot or interactive layout certification.

## Pending acceptance

Native Chromium default executable missing; installed /usr/bin/chromium also exited before opening a page. No browser bypass used. Native narrow-screen toolbar placement, desktop drag/click threshold/capture, touch dragging and browser page scroll, free-canvas card scrolling, screen readers, Windows and long-run/performance checks remain pending.

No wheel zoom, pinch/multi-touch zoom, tile map, out-of-crop feature recovery, higher-resolution geometry or automatic Locate recentering. Symbols/text magnify with geography. Locator shows original authored extent. Stories do not install reader panels in this batch. Each full editor re-render starts a fresh view. Bounds constrain movement to the original plot rectangle, which can contain authored padding. No claim of complete geographic parity or competitor-quality benchmark.
