## Semantics and budgets

Scroll/reading output reuses buildStorySources and the saved view resolver. Reading snapshots show each scene’s complete ending pose; animation timing does not determine reading time. Optional scroll transitions select nine samples from the existing overlap compositor; unsupported shapes/axes keep the existing crossfade fallback. Text is plain, not authored HTML. Empty chapter text is allowed; headings have deterministic Chapter N fallbacks.

Up to 24 scenes; title/text/description/introduction limits 120/4,000/1,000/2,000 characters. A 24 MiB content/payload budget rejects oversized output rather than dropping chapters. Existing animation GIF/video limits remain. Reading SVGs retain 960 × 540 geometry; no new adaptive chart-label reflow is claimed. Narrative embeds use a taller internal viewport, not automatic parent resizing. Published values are snapshots at export; there is no live network refresh.
