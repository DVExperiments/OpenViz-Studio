Contact sheet `v321-regional-symbol-frames.png` contains generated charts, not browser screenshots. New example retains five fictional regions, 35 positions, seven rings and one unmatched source row; no real administrative accuracy is implied.

A normal headless Chromium launch using /usr/bin/chromium failed (browser closed before a page opened). Native browser layout, file-picker, Windows persistence, screen readers and large realistic boundary performance remain pending.

Limitations: scanline anchors represent largest parts rather than true observations; circle footprints can overlap or cross holes/outlines, with no collision solver/manual anchors. Geometry structure checks do not certify full topology. Projection is local equirectangular, not equal-area. The count calculation counts all matched records; other symbol calculations exclude negative measures before aggregation. Regional time views aggregate records rather than enforcing one observation per entity. No new label/locator mode yet.
