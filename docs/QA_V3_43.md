## Pending native acceptance / boundaries

Normal /usr/bin/chromium launch exited before opening a page. Native layout, keyboard/focus/touch, screen readers, Windows and detailed performance acceptance remain pending. Full competitor parity unclaimed.

Only the Stacked columns template gains this playback path; existing static stacked behaviour is preserved. This is discrete snapshot delivery, not animated stacking interpolation. Net signs are determined after the selected per-cell aggregation. Positive/negative totals stack separately; no net-total label is inferred. Adding Means/Minima/Maxima may be inappropriate even when numerically supported. Count includes labelled rows regardless of measure; other methods require finite numeric cells. Missing category/series labels are excluded; exact string identity is used.

32 categories/10 series across the full timeline; first valid occurrence within ordered periods fixes slots. Palette slots stay stable but user-authored colours may coincide; per-cell overrides bypass legend colours. Zero has no area and may be hard to target with a pointer; keyboard details/source table remain available. Label clipping may shorten display, while mark details retain full names. Ten-series legends can consume space on narrow charts; detailed native acceptance pending.

60 periods/30,000 source rows/6 MiB player payload. Independent charts/filtered story sources have their own domains, not synchronized scales. Dashboard filtering keeps the unfiltered chart timeline scale/domains and saved period via compiler-only source references. Static/dashboard/story output uses saved period; interactive chart HTML includes all snapshot aggregates. Portable JSON and optional source tables may expose original records. No source mutation or network service is added.
