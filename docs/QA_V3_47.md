## Pending native acceptance / boundaries

Normal /usr/bin/chromium launch exited before opening a page. Native browser layout/keyboard/focus/touch, screen readers, Windows and detailed performance acceptance remain pending. Competitor parity unclaimed.

Only timed multi-line gains the new renderer; static multi-line is unchanged. Snapshot period is a separate field from X. Valid X/series labels establish the full known-X/series union even when measures are invalid. Numeric/date labels sort; other labels preserve first observed order within ordered snapshots. Date mode requires consistent valid ISO date-only values. Other date-like/mixed labels fall back to categorical mode, disclosed in editor warnings. Numeric X strings are interpreted numerically; identifiers should use appropriate text labels. Distinct labels at one numeric coordinate reject with a cleanup message.

Gaps are based on the full known X union across series/snapshots. Absent positions never present anywhere are not fabricated: ordinary straight segments can connect adjacent known observations across a longer interval. Explicit missing-measure rows retain gap positions. Count counts labelled rows, so an explicit missing measure can become a counted point. Missing labels are excluded. Y includes zero/all aggregate extremes, with 0–1 for all zero; singleton X centers without inventing another observation. Manual value bounds are overridden.

60 known X positions/10 series across timeline, 60 snapshots/30,000 rows/6 MiB player payload. Dense axis labels can be thinned/shortened; full X/series names remain in details. Date ticks use month-day for one year, shortened ISO labels across years, plus year caption/full ISO titles. Per-point overrides affect markers rather than whole series lines. Optional direct labels are restricted to sparse views. No interpolation between snapshots/carry-forward/source rewrite.

Dashboard filtering retains source domains/saved period. An aggregate outside fixed Y bounds breaks the line and uses a disclosed boundary marker; it is not silently joined/clamped into an in-range curve. Filtered aggregation overflow shows an error rather than partial paths. Independent charts/filtered story sources define their own domains. Static/dashboard/story delivery uses saved period; chart HTML embeds every snapshot. Portable projects and optional tables can expose source records.
