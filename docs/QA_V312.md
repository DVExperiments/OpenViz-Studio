# V3.12 validation

## Passed automated checks

- Race model: duplicate aggregation, numeric/ISO/source ordering, alphabetical ties, zero versus absent data, complete missing periods, optional zero assumption, negative/overflow guards, 120-period and 100-entity limits, immutable source and fixed global scale.
- Interpolation: exact endpoints, bounded seek position, labelled intermediate values, top-N enter/exit behaviour, and deterministic colours independent of period/entity filtering.
- Actual standalone scripts executed in jsdom with a deterministic requestAnimationFrame clock: initially paused, seek including fractional positions, Previous/Next, Play/Pause, finite ending, looping, disposal, reduced-motion fallback, escaped JSON payload and three responsive SVG scenes. No network services are needed.
- Editor: all 42 template field/preview/data/reviewed-source/undo workflows; dedicated race controls, transient next-period playback, explicit static-period capture with undo and missing-policy settings.
- Portable project fields, selected-period static/no-script HTML, interactive chart publishing and snapshot dashboard exports.
- Existing all-template geometry and HTML runtime suites, missing-value/research/field contracts, publishing, linked dashboard, rename/story, map note, storage and synthetic performance checks.

Commands: run Node suites in `tests/`; jsdom suites require OPENVIZ_DOM_MODULE pointing at an installed jsdom module. `tests/test-race-v312.mjs` specifically covers the race. `tests/render-race-v312.mjs OUTPUT_DIR` produces repeatable SVG fixtures for visual QA.

## Static visual QA

Actual SVG output was rasterised with CairoSVG and inspected at 360 and 960 logical widths for first/middle/last periods. This caught and corrected crowded numeric ticks on narrow canvases; axis tick density now depends on available bar width. Long entity/value labels are abbreviated visually with complete details in tooltips. Clip paths keep bars inside the row area during entry/exit. This is static rendering evidence, not browser animation certification.

## Remaining validation and limitations

Chromium could not launch in this environment during V3.11; no new claim of browser execution is made. Real browser/container-query/motion quality, screen-reader interaction, touch input, cross-browser behaviour and native Windows exports remain pending.

Only standalone chart HTML and the editor play races. Dashboard cards, story scenes, SVG/PNG/PDF/PPTX and existing motion/video exports use a saved period. No timeline mini-chart, images/flags, keyed captions, smallest-value mode, race recording, carry-forward or user-defined period ordering is provided yet. Steps have equal duration even when dates are unevenly spaced. Hidden/missing entities fade between endpoints; intermediate numbers are animation values, not source observations. All included aggregate frames are embedded in interactive HTML. Optional source tables remain bounded snapshots and do not follow the timeline.

No complete Flourish parity or chart-quality superiority is claimed.
