# V3.33 handoff

New map-exploration.js provides dependency-free installMapExploration and shared component CSS; map-exploration-meta.js emits escaped root/feature metadata only when geoExploreEnabled is true. DEFAULT_CHART defaults false; tooltip/classification validators enforce bool, and primitive VIEW_KEYS/portable paths persist the author flag. Map appearance adds checkbox/example; reading state never enters the project or Undo.

Feature IDs: canonical country, custom region shared area/symbol (prefer symbol), timed point entity key, static point place/position tuple. Visible search names use canonical country name or source place name; duplicate names expose IDs, ambiguous identical observation keys disclose ambiguity instead of merging details. Names and IDs are searched with accent/case folding, results capped at 20. Everything uses textContent, never source HTML. No data recomputation or field exposure beyond existing rendered titles/IDs.

One controller per time stage, dashboard frame or responsive chart group; visible SVG provides current details. Search/pin/current period update on frame changes and resize (window plus optional ResizeObserver). Missing pin stays selected with an unavailable message and recovers on return; missing regional geometry can still yield current No data. Pin body is scrollable/focusable. Clear/Locate keyboard support and temporary highlight. Capture-phase activation runs before dashboard redraw without cancelling its linking behaviour. No filters dispatched from search results.

Shared installChartInteractions owns exploration lifecycle. Self-contained interactionScript supplies the installer lexically; CSS travels through existing chart/dashboard exports. Editor options pass panelHost outside #liveChartSvg and an isEditing callback; published code contains no editor-only class marker. Core keyboard eligibility skips empty paths. Cleanup removes controller panels/highlights/observers/resize and activation listeners. Tooltip preview gets its own disposable instance.

Live editor and interactive chart/dashboard HTML support panels. Default off prevents unsolicited UI. Static exports rebuild clean SVG with no transient highlight/pin. Story views retain primitive flag/metadata but do not get controls this batch. Dashboard unlinked script now guards optional selection-status element. Free-canvas cards can scroll when an explorer panel is present; native acceptance pending.

Tests: test-map-exploration-v333.mjs and extended studio plus all prior groups, 34 suites pass. render-map-exploration-v333.mjs generates 20 SVGs/five text cards, five-chart/four-dataset/dashboard JSON and regional/timed-point standalone HTML.
