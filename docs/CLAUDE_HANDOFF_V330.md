# V3.30 handoff

New src/map-legend-format.js exports validateMapLegend, mapLegendMetrics and formatMapLegendValue. DEFAULT_CHART adds geoLegendAlign (left/center/right), geoLegendLayout (auto/list), geoLegendWidth (25–100 percent, default 100), geoLegendFontSize (9–16, default 9), geoLegendNumberFormat (auto/decimal/compact/scientific), geoLegendDecimals (0–6, default 2), geoLegendPrefix/Suffix (literal strings <=16). Validation is called by validateMapClassification, so existing portable/saved-scene paths validate these settings.

Formatter returns text/exact/approximate. Explicit formats use deterministic en-US digits, compact k/M/B/T with scientific fallback >=1e15, scientific mantissa decimals. Numeric rounding adds approximation mark. Negative zero is normalised. Prefix/suffix do not convert values; all renderer strings are escaped. Automatic uses previous raw/nonlinear precision policies. Class/domain model arithmetic, tooltip values and source data are unaffected.

Metrics cap width to plot, impose 120px minimum where possible, compute alignment shift and font scale relative to existing 9px layout. Legend rendering uses a display transform around the original plot-bottom origin; height reservation and class columns use matching logical width/scale. New metadata exposes actual block bounds/scale/layout/format. Font size scales title/body proportionately. Grid expands columns for complex/formatted labels; list uses one. Styled gradient tick values stagger onto three possible rows and reserve 32 logical pixels to retain scientific exponents/units at narrow widths. Default unstyled layout remains inline. Existing boundary-note placement follows reserved legend height.

Numeric display settings apply to ticks, class thresholds, midpoint/custom-domain/symlog-constant captions; exact titles/scale metadata retain values. App modal adds staged layout/number controls to existing classification manager. Continuous disables class layout, Auto disables decimals, both retain stored choices. New map-legend-example action uses fictional signed skewed data with right/list/compact kg controls. VIEW_KEYS already captures primitive settings; no schema version bump. Publishing generator 3.30.
