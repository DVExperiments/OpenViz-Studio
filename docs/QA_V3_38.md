## Limits / pending acceptance

Native /usr/bin/chromium exited before opening a page; no bypass. Native SVG focus/Locate, labels/layout at narrow widths, keyboard and touch, screen readers, Windows, physical export and larger-data performance acceptance remain pending.

This is the first route implementation, not a complete competitor replacement. Supplied coordinates only, no geocoding. Curves are illustrative latitude bows, not geodesics/actual paths; longitude follows shortest direction (180-degree tie resolves westward). Straight mode connects projected seam/clipped segment endpoints. Curved polar sections can flatten at latitude limits. Reciprocal/duplicate paths may overlap. One connection per valid row, no aggregation. Zero width can retain endpoint dots. Labels are capped/collision-aware; display label text is bounded to 300 characters. Row numbers are positions in the current input view, not immutable import row IDs.

First 500 valid rows drawn; size scale and Fit use all valid rows. Crop-only omissions are distinct from invalid input exclusions. Static key/accessible summary disclose excluded inputs; editor warnings give reasons. Very dense maps still need filtering. No automatic route time playback, custom-region joins, manual endpoint-label positioning or authored shared width domain. Static/fresh exports exclude transient pin/zoom state; stories use complete scene readers.

Next: aggregation, reciprocal separation and shared width scales.
