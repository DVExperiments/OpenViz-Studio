## Pending native acceptance / limits

Normal /usr/bin/chromium launch exited before opening a page. Native browser layout/keyboard/focus/touch, screen readers, Windows and detailed performance acceptance remain pending. Competitor parity unclaimed.

Only timed stacked-hbar gains the new rendering path; static rendering remains unchanged. The existing stacked-column domain model is reused without changing its type/kind semantics. Exact categorical cells aggregate per period, then current positive/negative results stack separately. Mixing signed records within one cell may cancel before stacking. Stack totals are separate from net totals. Means/minima/maxima can be numerically supported while inappropriate to add; editor warns.

32 categories/10 series across the full timeline; first valid occurrence in ordered periods fixes slots. Missing labels/nonfinite measures are excluded; Count requires labels but ignores measure. Zero markers can overlap at the same boundary; keyboard details remain available. Axis labels can be thinned/shortened; mark details keep full names. Direct numeric labels require sufficient space. Per-cell colours may differ from series legend.

60 periods/30,000 source rows/6 MiB player payload. All-zero domain is 0–1. Manual value bounds are ignored. Independent charts/filtered story sources define their own domains. Dashboard source references retain saved periods/full-source bounds/slots; visible cells are reaggregated, so removing cancellation or changing an average can exceed those bounds. Geometry clamps at the fixed limits with visible/tooltip clipping disclosure and raw values retained. Filtered numeric overflow rejects that view rather than drawing partial groups. Clipping is not a source-value change.

Static/dashboard/story delivery uses saved periods; interactive chart HTML includes all snapshot aggregates. Portable projects and optional source tables can expose original records. No interpolation, source rewrite or new network service.
