## Evidence limits

No full-suite or native-browser/Windows/touch/screen-reader/storage/performance/export-viewer acceptance is claimed. No official internal administrative boundaries or higher-resolution world dataset are newly bundled. The external providers’ pages are links/guides, not live integrations. Resources contain the existing snapshot with 1 collapsed ring/polygon omitted for strict regional import and 0 features removed; remaining geometry is not repaired or modernized. Global resource remains too broad for the custom regional importer, so its example uses the built-in world renderer. NE- identifiers are snapshot-local. Shape examples have clearly labelled placeholder 1 values; CSV templates have no fabricated measures.
