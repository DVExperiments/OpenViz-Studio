# OpenViz Studio — proposed milestones after V3.5

V3.5 completes the first Publishing Studio / embedding flow. The remaining versions are product proposals, not promises or certified functionality.

| Version | Candidate focus | Notable work |
|---|---|---|
| V3.5.1 | Publishing feedback and compatibility fixes | Host-specific iframe compatibility, small-screen polish, metadata/accessibility, QA fixes |
| V3.6 | Professional Story Studio | Audio track, audio/image synchronization, timeline refinement, more deliberate video output formats and narration workflows |
| V3.7 | Creative design power | Stronger reusable design tokens, advanced labels and typography, templates for academic/editorial publishing |
| V3.8 | Data storytelling and sharing | Guided narrative blocks, accessible notes/captions, better web story player and transitions |
| V3.9 | Final beta performance & quality | Large-story optimization, cross-browser checks, WCAG testing, security/privacy and storage validation |
| V4.0 | Potential public beta / stable milestone | Only after real-world QA sign-off, published documentation and support workflow |

Keep the main product focus on free professional visualisation, not duplicating Excel. Preserve browser-first, local-first operation, editable project backups, accessible UI, no mandatory AI, and transparent export limitations.
