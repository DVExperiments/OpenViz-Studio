## Limits

Likert shows the first 14 questions and requires 3–9 explicitly ordered labels. Interval shows the first 24 valid rows. ECDF shows the first six cohorts and blocks above 5,000 distinct values in a displayed cohort; hover markers may be sampled to 80 but the step path is exact. Calendar shows one full year with Monday-first weeks; interactive files include up to the latest 12 data years plus the selected year. Assumption lens displays the first 12 groups but computes ranks over every matched eligible group. These limits are disclosed in chart warnings.

Intervals are supplied values, not automatic confidence intervals. Assumption lens cannot establish causality or determine the correct aggregation/missing-data rule. Averages and sums can answer different questions. Calendar uses ISO date prefixes as written; numeric spreadsheet date serials require conversion before use. Unknown/nonfinite values are excluded or blocked with guidance, never recovered. Truncated row labels retain full mark tooltips.

Browser UI, keyboard/screen-reader accessibility, native Windows exports, external hosting, cross-browser rendering and real-origin IndexedDB persistence remain unverified in this environment.
