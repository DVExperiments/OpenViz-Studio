## Passed automation

36 suites including extended test-studio-v37.mjs. New test-story-maps-v335.mjs executes generated story HTML in jsdom and checks:

- Complete final scene explorer, explicit pause on open, repeated open/close, fresh pin/zoom state and no controls on animation stage.
- Saved periods/current details when moving scenes; play/navigation close exploration. Exploration mutates no project/source state or Undo entries.
- Reading chapter independence, sticky chapter lifecycle, controls absent during transition frames and fresh controls afterward.
- Reduced-motion complete views; narrow reading fallback, explicit navigation while controls own focus; layout change cleanup.
- Unique nested SVG IDs and resolvable clipping references across player/exploration and chapter/sticky copies.
- Portable flags, clean interactive publication, static/no-JS reading with no controls/scripts, transient pin/view excluded from output and source safety.

Earlier suites cover raw SVG numeric/geometry, map navigation/search, scene state/filter/period, scroll navigation/deep links and rendering/export contracts. Extended Story Studio checks open/reopen, scene switch, play-to-explore pause, page-leave cleanup and Undo.

## Acceptance limits

/usr/bin/chromium exited before opening a page under a normal launch. No bypass attempted. Native desktop/mobile chapter layout, scroll/focus protection, pointer capture/touch, screen readers, Windows, actual export performance and long-session resource use remain pending. DOM checks do not certify those behaviours.

Scene exploration intentionally uses complete saved scene values rather than interpolated animation frames. It opens a second paused view beneath the animation. Reopen/scene changes reset transient state. Reading and sticky views are independent; sticky controls are absent during transitions. Focus in sticky controls pauses passive chapter replacement until focus leaves; explicit chapter navigation still works. Existing chart option defaults and captured-scene overrides apply. No wheel/pinch zoom or Locate recentering yet. Static/no-JS exports have no reader controls.
