## Pending native acceptance / limits

Normal /usr/bin/chromium launch exited before opening a page. Native browser layout/keyboard/focus/touch, screen readers, Windows and detailed performance acceptance remain pending. Competitor parity unclaimed.

Only timed percent-bar/percent-hbar use the new path; existing static percentage templates are preserved. Shares normalize available valid per-category/per-period cell aggregates. This does not infer unknown contributors or prove a complete composition. Missing-series count is relative to the valid full-timeline series universe, not an external expected schema. Blank labels are excluded; other missing/nonfinite measures are excluded except Count. Negative source records with valid labels reject numeric playback; negative values in excluded/no-period records are not contributors. Count counts labelled records regardless of measure. Numeric zero, zero-total and no-data are different states.

Details show six-significant-digit shares; raw values/totals use selected formatting plus exact numeric strings when formatting changes them. Floating-point rounding and tiny shares can affect display precision. Positive shares are bounded when accumulating geometry to prevent visual overshoot. Zero markers may overlap at an all-zero baseline; individual details remain in keyboard navigation. No interpolation, carry-forward or fabricated years.
