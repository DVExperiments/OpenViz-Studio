# V3.7.1 — column renaming patch QA

The old rename control was a small pencil beside a non-interactive name. The full heading is now a keyboard-focusable rename button with an explicit Rename hint. Column removal remains a separate button. Studio column letters decorate the new header button. Blank/duplicate/invalid names display an inline role=alert message and aria-invalid field state, instead of relying on a toast behind the modal.

The existing rename implementation still updates chart field mappings and calculation references while preserving values and rawRows. Chart editor layout and rendering are unchanged.
