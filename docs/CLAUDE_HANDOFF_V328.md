# V3.28 handoff

New DEFAULT_CHART fields: geoDomainMode ('auto' default / 'custom'), geoDomainMin and geoDomainMax (null defaults). validateMapClassification permits finite inactive endpoints, requires ordered finite-span endpoints for active custom domains, restricts custom to Continuous/Equal interval and requires a diverging midpoint strictly between endpoints. Portable imports and saved scene normalisation use this existing validator.

classificationModel retains min/max as observed data extrema, adds scaleMin/scaleMax/customDomain and below/above matched-aggregate counts. Custom equal breaks use authored bounds even with empty/one-sided/constant observations. Custom diverging endpoints override fitting (internal rangeMode 'custom'); stored independent/symmetric preference remains. The custom neutral interval uses authored breaks regardless of observed midpoint presence, and class colours sample authored bounds. Automatic and manual/quantile paths retain previous behaviour. Continuous colours clamp to endpoints; actual observations stay unchanged.

renderClassLegend adds data-map-domain-mode and data-map-observed-domain, keeps data-map-scale-domain describing actual display limits, discloses custom range and out-of-range counts. Height reservation grows by 44 pixels. Existing pooled time classification automatically fixes endpoints/breaks/counts across periods; static reports use current aggregates. No-data and explicit per-feature overrides remain separate. Country/custom renderers already share the classifier; no data/geometry/aggregation changes.

App classification modal adds mode/min/max controls and staged validation. Custom disables automatic diverging fitting controls; unsupported methods switch mode to Auto while preserving saved endpoint values. New example action creates illustrative custom limits −20…60. VIEW_KEYS captures new primitive fields without a separate schema change. Publishing generator 3.28.
