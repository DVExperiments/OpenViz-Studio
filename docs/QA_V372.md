# V3.7.2 — dashboard, navigation and data connection QA

## Changes

The linked-filter strip used the undefined --surface token with a white fallback, causing a white surface in dark mode. It now uses --panel. The dashboard chart wrapper is transparent, allowing saved SVG backgrounds to remain authoritative. Filter labels, selectors and buttons now align along their bottom edge; layout controls have consistent sizing; card headers reserve consistent space and grid cards stretch. Narrow containers wrap the dashboard heading controls.

The five project sections use native details/summary disclosures. Add buttons are separate siblings, so adding an item does not toggle its section. Expanded state persists via project-tree-sections browser preference, not in .openviz data. Reduced motion is respected.

Change data appears beside the current dataset in Preview and opens/focuses the top-level Chart data source selector. The same dataset selector is removed from the bindings panel to avoid duplication. The existing source-selection implementation and undo path are retained; users are explicitly asked to review column bindings after switching, especially for a different schema. No new source-switch remapping algorithm was introduced.
