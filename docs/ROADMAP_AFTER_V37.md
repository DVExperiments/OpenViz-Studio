# OpenViz Studio — roadmap after V3.7

V3.7 implements the requested Preview/Data studio workflow. Treat this as a development build pending user review and real-browser acceptance.

1. Review the studio layout on a normal browser origin; fix visual and interaction findings before expanding scope.
2. Finish the V3.7 browser matrix: every template, narrow screens, keyboard/screen reader access, data refresh, local persistence and export comparison.
3. Refine chart typography, defaults and labels with actual rendered examples and user feedback. V3.7 did not change the underlying chart renderer or certify every chart's visual quality.
4. V3.8 proposal: catalogue examples, accurate mappings, clear aggregation and trustworthy non-AI recommendations.
5. V3.9 proposal: cross-browser accessibility, persistence and export fidelity.
6. Public beta only after usability and data-integrity acceptance.

Retain the product focus: free professional data visualisation, strong defaults and deep customisation. Defer unrelated audio/video workspaces, accounts, AI integration and unfinished chart expansion.
