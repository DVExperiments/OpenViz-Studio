## Pending acceptance / limits

Native /usr/bin/chromium exited before opening a page; no bypass. Native getBBox and nested SVG CTM across browsers, mark keyboard focus, nearest-page scrolling, sticky chapter focus protection, touchscreen interaction, screen readers, Windows and performance acceptance remain pending.

Bounding rectangles can encompass disconnected/antimeridian parts or empty space; no geographic centroid or exact polygon-fit claim. Only existing rendered/cropped geometry is used; no geocoding, new data, tile detail or out-of-crop recovery. Bounds clip to the original plot rectangle. Point zoom caps at 4×, region at 8×; symbols/data are not rescaled in the chart model. The original locator still shows the authored extent. No wheel/pinch zoom. Static/fresh outputs use authored framing. No full Flourish parity claim.
