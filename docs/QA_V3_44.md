## Pending native acceptance / limits

Normal /usr/bin/chromium launch exited before opening a page. Native browser layout/keyboard/focus/touch, screen readers, Windows and detailed performance acceptance remain pending. Competitor parity unclaimed.

Only grouped-bar/grouped-hbar gain these snapshots; static expanded rendering remains intact. Cells use exact string category/series identity and valid main-measure contributors in each observed period. Blank labels are excluded. Count includes labelled missing-measure records; other methods exclude nonnumeric/missing measures. Numeric booleans are not treated as measures by the timed cell engine. Zero markers are distinct from missing cells. No carry-forward, zero filling or interpolation.

32 categories/10 series across the timeline; full slots/legend can be dense at narrow widths. Axis labels may be shortened or thinned; keyboard/hover details keep complete names. Numeric direct labels are shown only when sparse/enough room. Per-cell overrides can differ from the series legend; chosen base colours may coincide. Common bounds include zero, use individual cell values (not stacked totals), and override manual axes. Domains and horizontal label margins are stable across periods of the same authored view; changing author settings can change layout.

60 periods/30,000 rows/6 MiB player payload. Independent charts and filtered story sources have their own domains. Dashboard filters retain the unfiltered chart's timeline reference and saved period. Interactive chart HTML embeds all snapshots; static/dashboard/story output uses saved period. Portable JSON and opt-in source tables can include source records. No source mutation or new runtime network service.
