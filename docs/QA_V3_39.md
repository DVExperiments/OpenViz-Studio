## Pending acceptance / limits

Native /usr/bin/chromium exited before opening a page; no bypass. Native curve rendering/keyboard/Locate, narrow controls, touch, screen readers, Windows and detailed performance acceptance remain pending.

Grouping is exact directed coordinate/full-label identity; no fuzzy joining. Label display can be shortened while identity remains full. Negative/missing magnitudes are excluded when mapped, including Count; unmapped Count ignores unused magnitude columns. Group row positions refer to the current view, not immutable import IDs. First eight positions shown when there are more contributors.

Reciprocal separation only applies when both directions exist in the current view; same-direction duplicate paths may overlap. Small/polar/cropped links may have limited visible separation. Separated antipodal ties use a consistent half-circle; other longitude ties retain the earlier policy. Curves remain illustrative, not geodesics or travel paths. Shared limits are per-chart/scene values, not automatic cross-chart synchronization; same max line width and display scale are needed for visual comparison. Uniform mode ignores shared magnitude limits. Above-limit values saturate visually, not numerically; key/summary/tooltips disclose capping.

Cap applies after grouping, with auto max/Fit from all valid connections. No automatic route time playback in this batch. Native acceptance and full competitor parity remain unclaimed.
